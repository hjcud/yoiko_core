# よいこ Server Core

よいこ 코블몬 서버에서 사용하는 NeoForge 1.21.1 기반 핵심 모드의 소스 코드 저장소입니다.

## 공개 범위

이 저장소에는 다음 항목만 포함합니다.

- `src/main/java` 아래의 Java 소스 코드
- 의존성과 프로젝트 구조를 설명하는 Gradle 빌드 설정
- NeoForge 모드 메타데이터 템플릿
- 저장소 관리에 필요한 최소 설정 파일

다음 항목은 포함하지 않습니다.

- PNG, GIF 등 이미지와 원본 그림 파일
- 언어, 모델, 애니메이션, 지오메트리, 데이터팩 등 게임 리소스
- 코블몬을 비롯한 외부 모드와 외부 모드에서 추출한 자료
- 개발용 참고 자료, 설계 문서, 로그, 백업, 생성 결과물
- JAR 및 컴파일된 클래스와 같은 바이너리 파일

## 주의 사항

이 저장소는 코드 공개와 변경 이력 관리를 위한 저장소입니다. 실행에 필요한 리소스와 외부 모드가 포함되어 있지 않으므로, 이 저장소만으로 완성된 모드를 빌드하거나 배포할 수 없습니다.

프로젝트의 소스 코드는 별도 표시가 없는 한 모든 권리를 보유합니다. 외부 프로젝트의 이름과 API는 각 권리자에게 귀속됩니다.
